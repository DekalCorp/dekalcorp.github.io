Dekal

3D modeling tool for accelerated aircraft design

Dekal lets you design precise and differentiable aircraft geometries using a new hybrid 3D modeling kernel. The kernel combines the robustness of implicit modeling with the expressiveness and file generation capabilities of conventional BRep engines.

01

The model is defined as an implicit program

A user can define sketch profiles, loft, blend and union in a similar fashion to conventional BRep CAD. In this case, we model a wing blended into a fuselage. But any other drone geometry can be described and modeled.

02

Dekal extracts true topology and generates a precise watertight mesh

Dekal does not use conventional isosurface extraction like marching cubes or dual contouring. Instead, Dekal derives the boundary’s topology first — which faces exist, which edges bound them, where the vertices are — and only then meshes the resulting cells. Neighbouring faces share the same edge data by construction, so the mesh welds rather than being stitched together by tolerance: no cracks, no doubled-up seam vertices, and a surface that closes every time.

03

Change the parameters, the topology holds

The same faces, the same edges, the same vertices are preserved through parameter changes. This lets us preserve and remap the same mesh topology between the simulation iterations, which preserves smooth gradients.

04

The whole pipeline is differentiable

Geometry, the field→boundary derivation and the physics all live on one intermediate representation, so a gradient runs from an objective back to the design parameters. This lets us optimize a given set of parameters by minimizing the output of a loss function. The optimization is fast and compute efficient.

05

And it exports as a real solid

The boundary is emitted as a STEP, with conic sections carried as exact rational NURBS. The geometry can directly be used by the mechanical team for the detailed design process. This type of workflow is currently not possible with conventional implicit modelers.
